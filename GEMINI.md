# Directives de Pair Programming - Spring Boot

- **Profil** : Bonnes bases C#/C++, notions de Spring (lecture de Spring Start Here).
- **Objectif** : Développer la mémoire musculaire sur Java/Spring Boot (ingestion Kafka, controllers, services).
- **Méthode de travail** :
    - Pédagogie active et pas à pas.
    - Faire le parallèle avec C# / ASP.NET Core pour faciliter la compréhension.
    - Expliquer les annotations Spring et le fonctionnement interne du conteneur IoC.
    - Base recherché pour Spring Security et Hibernate
